# Contributing

Keep changes small and state which evidence supports them: synthetic tests, local builds, live device behavior, or owner review. Include exact model and firmware information for hardware reports.

Do not submit private addresses, account identifiers, credentials, device tokens, databases, raw logs, firmware, extracted Samsung assemblies, or decompiled Samsung source. New compatibility claims need a separate documented profile and device evidence. Read [development](docs/development.md) before proposing a new target.

Public dependency source belongs under its original license; Samsung-derived inputs remain local. There are no credentials or proprietary runtime binaries required in the public tree.
