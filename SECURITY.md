# Security and privacy

This toolkit intentionally runs powerful operations on an owner's TV. Use a trusted local network and keep development access off public interfaces. No password-based root account or persistent public command service is installed by this project.

The root route is separately maintained public research. Read its source and prerequisites before use. This project pins a source revision rather than silently tracking future changes. Unexpected compatibility failures remain failures.

Keep configuration, records, snapshots, payloads, and device-derived binaries private. Local root logs can contain sensitive command output. Sharing a source folder is not the same as sharing `.local/`.

For a newly discovered vulnerability or sensitive exposure, contact the maintainer through the hosting platform's private security-reporting facility when available. Do not post exploit access details, device credentials, or personal logs in a public issue. Ordinary customization bugs can be reported with redacted diagnostic excerpts.
